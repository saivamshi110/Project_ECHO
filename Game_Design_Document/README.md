# Game Design Document (GDD)

## Overview

The Game Design Document (GDD) defines the creative vision of **ECHO: The Living World**. It serves as the primary reference for gameplay mechanics, world-building, player experience, design philosophy, and overall project direction.

The purpose of this document is to ensure that every aspect of the game is planned before implementation begins.
